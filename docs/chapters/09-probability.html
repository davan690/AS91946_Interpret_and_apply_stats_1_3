13  Probability

Probability is a measure of how likely an event is to occur. It is expressed as a number between 0 (impossible) and 1 (certain), or as a percentage.

\[P(\text{event}) = \frac{\text{number of favourable outcomes}}{\text{total number of possible outcomes}}\]

13.1 Probability scale

13.2 Key vocabulary

Term Definition
Experiment A process with uncertain outcomes
Outcome A single possible result
Event One or more outcomes grouped together
Sample space The set of all possible outcomes
Complementary event All outcomes that are NOT in the event

13.3 Simple probability — equally likely outcomes

When all outcomes are equally likely, we can use the classical definition.

13.3.1 Example: rolling a die

Show R code 
sample_space <- 1:6
cat("Sample space:", sample_space, "\n")
#> Sample space: 1 2 3 4 5 6

# P(rolling a 4)
p_four <- sum(sample_space == 4) / length(sample_space)
cat("P(rolling a 4) =", p_four, "\n")
#> P(rolling a 4) = 0.1666667

# P(rolling an even number)
p_even <- sum(sample_space %% 2 == 0) / length(sample_space)
cat("P(even number) =", p_even, "\n")
#> P(even number) = 0.5

# P(rolling > 4)
p_gt4 <- sum(sample_space > 4) / length(sample_space)
cat("P(> 4) =", p_gt4, "\n")
#> P(> 4) = 0.3333333

13.4 Complementary events

The complement of event A (written A’ or \(\bar{A}\)) contains all outcomes NOT in A.

\[P(A') = 1 - P(A)\]

Example: If the probability of rain tomorrow is 0.3, then:

\[P(\text{no rain}) = 1 - 0.3 = 0.7\]

Show R code 
p_rain <- 0.3
p_no_rain <- 1 - p_rain
cat("P(rain) =", p_rain, "\n")
#> P(rain) = 0.3
cat("P(no rain) = 1 -", p_rain, "=", p_no_rain, "\n")
#> P(no rain) = 1 - 0.3 = 0.7

13.5 Experimental (relative frequency) probability

When we cannot calculate probability theoretically, we estimate it by repeating an experiment many times:

\[P(\text{event}) \approx \frac{\text{number of times event occurred}}{\text{total number of trials}}\]

13.5.1 Simulating coin flips

Show R code 
set.seed(99)
flips  <- sample(c("Heads", "Tails"), 1000, replace = TRUE)
cumulative_heads <- cumsum(flips == "Heads") / seq_along(flips)

plot(
  cumulative_heads,
  type = "l",
  col  = "#0571b0",
  lwd  = 1.5,
  xlab = "Number of Flips",
  ylab = "Relative Frequency of Heads",
  main = "Simulated Coin Flips",
  ylim = c(0, 1),
  las  = 1
)
abline(h = 0.5, col = "#d7191c", lwd = 2, lty = 2)
legend("topright", c("Relative frequency", "True probability (0.5)"),
       col = c("#0571b0", "#d7191c"), lwd = 2, lty = c(1, 2), bty = "n")
NoteLaw of Large Numbers

As the number of trials increases, the relative frequency (experimental probability) gets closer and closer to the true probability. This is why surveys and experiments need large samples.

13.6 Two-way tables

A two-way table (contingency table) organises data by two categorical variables and is very useful for calculating probabilities.

Show R code 
# Simulated data: 120 students, sport preference by gender
set.seed(7)
n_students <- 120
sport_data <- data.frame(
  Gender = sample(c("Male", "Female"), n_students, replace = TRUE,
                  prob = c(0.5, 0.5)),
  Sport  = sample(c("Rugby", "Netball", "Football", "Basketball"),
                  n_students, replace = TRUE, prob = c(0.3, 0.25, 0.25, 0.2))
)

tbl <- table(sport_data$Sport, sport_data$Gender)
tbl_with_total <- addmargins(tbl)
knitr::kable(tbl_with_total, caption = "Sport preference by gender (n = 120)")
Sport preference by gender (n = 120)
Female Male Sum
Basketball 16 11 27
Football 13 17 30
Netball 18 17 35
Rugby 16 12 28
Sum 63 57 120

13.6.1 Reading probabilities from a two-way table

Using the table above:

Show R code 
total <- sum(tbl)

cat("P(Male) =", sum(tbl[, "Male"]), "/", total, "=",
    round(sum(tbl[, "Male"]) / total, 3), "\n")
#> P(Male) = 57 / 120 = 0.475

cat("P(Rugby) =", sum(tbl["Rugby", ]), "/", total, "=",
    round(sum(tbl["Rugby", ]) / total, 3), "\n")
#> P(Rugby) = 28 / 120 = 0.233

cat("P(Male AND Rugby) =", tbl["Rugby", "Male"], "/", total, "=",
    round(tbl["Rugby", "Male"] / total, 3), "\n")
#> P(Male AND Rugby) = 12 / 120 = 0.1

cat("P(Rugby | Male) =", tbl["Rugby", "Male"], "/",
    sum(tbl[, "Male"]), "=",
    round(tbl["Rugby", "Male"] / sum(tbl[, "Male"]), 3), "\n")
#> P(Rugby | Male) = 12 / 57 = 0.211

The last probability — P(Rugby | Male) — is a conditional probability: the probability of preferring rugby, given the student is male.

13.7 Tree diagrams

Tree diagrams help calculate probabilities for sequential events.

Key rule: Multiply probabilities along each branch, add probabilities for different paths leading to the same outcome.

13.8 Expected value (extension)

For a simple scenario, the expected value is the long-run average outcome:

\[E(X) = \sum x \cdot P(x)\]

Example: A raffle has 200 tickets at $2 each. First prize is $100, second prize is $50. What is the expected gain per ticket?

Show R code 
outcomes  <- c(100, 50, 0)         # winnings
probs     <- c(1/200, 1/200, 198/200)
cost      <- 2

expected_win  <- sum(outcomes * probs)
expected_gain <- expected_win - cost

cat("Expected winnings:", expected_win, "\n")
#> Expected winnings: 0.75
cat("Ticket cost:      ", cost, "\n")
#> Ticket cost:       2
cat("Expected net gain:", expected_gain, "\n")
#> Expected net gain: -1.25
cat("(A negative expected gain means this is not a good investment!)\n")
#> (A negative expected gain means this is not a good investment!)

13.9 Glossary

Term Definition
Probability Likelihood of an event, from 0 to 1
Sample space All possible outcomes
Event One or more outcomes
Complement All outcomes NOT in the event
Relative frequency Experimental estimate of probability
Conditional probability P(A given B): probability of A given B occurred
Two-way table Table showing two categorical variables together
Tree diagram Diagram showing sequential outcomes and probabilities

13.10 Check your understanding

  1. A bag contains 4 red, 3 blue, and 3 yellow marbles. A marble is drawn at random. Find:
    1. P(red)
    2. P(not red)
    3. P(blue or yellow)
  2. A class of 30 students was surveyed: 18 play sport, 12 play an instrument, and 6 do both.
    1. Draw a Venn diagram.
    2. Find P(plays sport but not instrument).
    3. Find P(neither sport nor instrument).
  3. If P(A) = 0.4 and P(B) = 0.3 and A and B are independent, find P(A and B).
NoteAnswers
    1. 4/10 = 0.4; b. 6/10 = 0.6; c. 6/10 = 0.6
    1. 12/30 = 0.4; c. (30 − 18 − 12 + 6)/30 = 6/30 = 0.2
  3. P(A and B) = 0.4 × 0.3 = 0.12 (for independent events)
